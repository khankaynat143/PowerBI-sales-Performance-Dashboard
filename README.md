# Retail Sales Performance Dashboard (Power BI)

## Project Overview
This project analyzes retail sales data to track revenue, sales trends, and overall business performance using Power BI.

## Tools Used
- Power BI
- SQL
- Excel

## Key KPIs
- Total Sales
- Total Revenue
- Sales Trend
- Region-wise Performance

## Business Insights
- Identified top-performing regions and products
- Analyzed monthly and yearly sales trends
- Supported data-driven business decisions

## Dataset
Publicly available retail sales dataset.
